# 一箭又一箭

> 软件工程课程第二次个人作业 · 学号 102401129
> 使用 Python + Pygame 开发的点击式箭头解谜小游戏，借助 AIGC 工具辅助完成。

## 项目简介

“一箭又一箭”是一类点击式箭头解谜游戏。棋盘上分布着朝 **上 / 下 / 左 / 右** 四个方向的箭头，玩家需要观察箭头的方向与相互阻挡关系，按合适顺序依次点击箭头，让所有箭头飞出棋盘。

核心规则：

- 点击一支箭头时，程序检查它**前进方向上（同一行或同一列、直到棋盘边界）**是否还有其他箭头；
- **无阻挡** —— 箭头飞出棋盘并消失；
- **有阻挡** —— 箭头不能消失，发生碰撞反馈（晃动 + 变红），并消耗 1 次失误机会；
- 清空本关全部箭头即**通关**；最后一支箭头会先完整飞出棋盘（飞出动画播完），再弹出通关画面、进入下一关；
- 失误次数耗尽则**失败**，可重新开始本关；
- 每关失误上限**统一为 3 次**，每关最高 **3 星**：每失误、撤销、提示一次各扣 1 星（见下节）；
- 共 **20 个固定关卡**，难度逐步加深：从主菜单进入**选择关卡**二级菜单，关卡按顺序解锁（通关第 N 关解锁第 N+1 关），已通关关卡可任意重玩；通关进度只保存在内存里，**程序不关闭就保留，退出程序即重置**。

## 失误与星级规则

每一关的失误上限统一为 **3 次**。失误既决定「能否通关」，也参与扣星；撤销、提示各只有 1 次机会，同样扣星：

| 情形 | 本关星数 |
| --- | --- |
| 不用辅助、不失误 | 3 星 |
| 失误 1 次，或撤销 1 次，或提示 1 次 | 2 星 |
| 累计扣 2 项（如失误 2 次、失误 1 次 + 撤销 1 次） | 1 星 |
| 累计扣 3 项及以上（如失误 2 次 + 撤销 1 次） | 0 星 |
| 使用过 AI 自动求解 | 固定 1 星（不论是否同时失误 / 用辅助） |

- **星数下限为 0**，不会变负：失误 3 次直接失败、无法通关，所以「能通关的最坏情况」是失误 2 次 + 撤销 + 提示 = 扣 4 项，取整后为 0 星；
- **撤销、提示各只有 1 次机会**；第二次点击时机会数已为 0，程序会提示「机会已用完」且不做任何改动；
- **用 AI 自动求解固定只给 1 星**，优先级高于上面的扣分规则；
- 固定关卡共 **20 关**，满分 **60 星**。顶部状态栏实时显示**累计星数**与**本关剩余星数**，通关界面显示本关所得，全部通关界面显示总星数；
- 固定关卡**按关保存历史最佳星数**：重复游玩同一关按最佳成绩计分，总星数 = 各关最佳之和，重玩不会重复加分、也不会退星；
- 中途重新开始本关，固定关卡保留已记录的最佳星数；随机模式按本局累计计分，重开时退回本关已计入的星数，避免重复计分。

## 开发环境

| 项 | 说明 |
| --- | --- |
| 操作系统 | Windows 10/11 |
| Python | 3.10（≥ 3.8 均可） |
| 图形库 | Pygame / pygame-ce 2.5.8 |
| 数值库 | NumPy 1.24+（运行时合成音效） |
| 开发工具 | AIGC 编程助手（Claude / ZCode）+ Git |
| 字体 | 系统自带 Microsoft YaHei（`msyh.ttc`），无需额外素材 |

本项目**不依赖任何外部图片素材或音频文件**：箭头与界面均由 Pygame 绘制；8 个音效（射出、阻挡、按钮、撤销、提示、通关、失败、通关庆祝）全部由 NumPy 在运行时合成波形生成——正弦 / 三角 / 方波 / 锯齿波 + 白噪声、线性扫频与淡入衰减包络，逐段拼接。没有安装 NumPy 或音频设备不可用时，音效自动静音，其余功能不受影响。

## 安装与运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行游戏
python arrow_game.py
```

> 若在无显示器的服务器上想快速验证逻辑，可运行自动化测试：
> ```bash
> python test_game.py          # 10 项逻辑测试（含随机模式、AI 求解、星级规则与选关菜单）
> python verify_levels.py      # 验证 20 个关卡均可通关
> python make_screenshots.py   # 重新生成 README / 博文中的界面截图
> ```

### 打包成可执行文件（可选）

本项目不携带任何图片、音频或字体文件，所以可以直接打成单个 exe，**目标机器无需安装 Python**：

```bash
pip install pyinstaller
python build_exe.py
```

产物为 `dist/一箭又一箭.exe`（约 24 MB，`--onefile --windowed`，双击即玩，无控制台窗口）。中文界面使用系统自带的微软雅黑（`msyh.ttc`），无需额外分发字体。`build/` 与 `dist/` 属构建产物，已在 `.gitignore` 中排除；如需把 exe 一并提交仓库，用 `git add -f dist/`。

## 游戏操作说明

> 游戏界面底部提供**按钮栏**：撤销 / 提示 / AI求解 / 重新开始 / 截图 / 音效 / 返回菜单——**纯鼠标即可完成全部操作**，键盘快捷键同样保留。

游戏流程：**主菜单 → 选择关卡（二级菜单）→ 游戏界面 → 通关 / 失败界面 → 全部通关**。主菜单点「开始游戏」进入选关界面；20 关按顺序解锁（通关第 N 关解锁第 N+1 关），已通关的关卡可以任意重玩；通关 / 失败界面的返回按钮回到选关界面。通关进度只保存在内存里——**只要程序不关闭就保留**，退出程序后重新开始即归零。

| 操作 | 作用 |
| --- | --- |
| 鼠标左键 | 点击箭头，尝试让其飞出棋盘 |
| 底部按钮栏 | 撤销、提示、AI求解、重新开始、截图、音效开关、返回菜单 |
| `R` | 重新开始当前关卡（快捷键） |
| `Z` | 撤销上一步（快捷键） |
| `H` | 提示当前可飞出的箭头（快捷键） |
| `S` | AI 自动求解当前关卡（快捷键） |
| `M` | 开关音效（快捷键；按钮文字同步显示「音效：开 / 关」） |
| `空格` / `回车` | 开始 / 下一关 / 失败后重试（快捷键） |
| `ESC` | 返回菜单 / 再按退出（快捷键） |
| `F2` | 保存当前画面截图（快捷键） |

界面元素：顶部状态栏显示 **当前关卡、剩余箭头数、剩余失误次数（圆点）、撤销 / 提示剩余次数、累计星数与本关实时星数**；底部按钮栏提供全部操作按钮；按钮栏上方有一条半透明提示气泡，操作反馈不会压住按钮。

## 关卡说明

共 **20 个固定关卡**，失误上限**统一为 3 次**，棋盘从 5×5 逐步扩大到 8×8，箭头数从 4 支逐步增加到 26 支：

| 关卡 | 名称 | 规模 | 失误上限 | 设计要点 |
| --- | --- | --- | --- | --- |
| 1 | 初识箭阵 | 5×5 / 4 箭 | 3 | 热身，含一处依赖 |
| 2 | 小试锋芒 | 6×6 / 8 箭 | 3 | 多方向散布，逐步熟悉 |
| 3 | 渐入佳境 | 6×6 / 10 箭 | 3 | 箭头增多，二维交叉 |
| 4 | 左右逢源 | 7×7 / 12 箭 | 3 | 更大棋盘，四处牵制 |
| 5 | 密阵初现 | 7×7 / 15 箭 | 3 | 双列/双行分头突破 |
| 6 | 迷雾重重 | 8×8 / 18 箭 | 3 | 8×8 棋盘，左右呼应 |
| 7 | 箭雨滂沱 | 8×8 / 22 箭 | 3 | 22 支箭，依赖渐深 |
| 8 | 万箭归宗 | 8×8 / 25 箭 | 3 | 首个高密度关卡，需整体规划 |
| 9 | 阵云密布 | 8×8 / 24 箭 | 3 | 密集布局，入口点分散 |
| 10 | 箭走游龙 | 8×8 / 24 箭 | 3 | 长链依赖，顺序敏感 |
| 11 | 乱箭交错 | 8×8 / 25 箭 | 3 | 行列双向交叉 |
| 12 | 矢影重重 | 8×8 / 25 箭 | 3 | 多点牵制，需反复权衡 |
| 13 | 箭阵连环 | 8×8 / 25 箭 | 3 | 连环依赖，一步牵动全局 |
| 14 | 矢海沉舟 | 8×8 / 26 箭 | 3 | 密度进一步提升 |
| 15 | 万矢齐发 | 8×8 / 26 箭 | 3 | 高密度 + 深依赖 |
| 16 | 天罗地网 | 8×8 / 26 箭 | 3 | 网格式相互封锁 |
| 17 | 群矢破空 | 8×8 / 26 箭 | 3 | 多处突破口，选择困难 |
| 18 | 箭神之境 | 8×8 / 26 箭 | 3 | 依赖深度最大 |
| 19 | 万箭穿云 | 8×8 / 26 箭 | 3 | 长链 + 密集混合 |
| 20 | 箭阵终极 | 8×8 / 26 箭 | 3 | 通关最后一关，累计满分 60 星 |

每个关卡都由 `generate_random_level` 以固定种子生成（生成脚本见 `gen_new_levels.py`）：箭头尽量随机分布（杜绝整行同向、连续同向过长、箭头扎堆），并都经过 `verify_levels.py` 的 DFS 求解器验证可通关。第 1~8 关的布局与改动前完全一致，便于对照与回归测试。

## 主要功能与特色

- **完整游戏流程**：开始界面 → 选择关卡（二级菜单）→ 游戏界面 → 通关 / 失败界面 → 全部通关；
- **正确的四方向路径检测**：同一行 / 列、到边界的阻挡判断，边界朝外不越界；
- **飞出 + 碰撞动画**：飞出箭头带渐隐位移动画，碰撞箭头带晃动与红色高亮；
- **失误机制**：圆点直观显示剩余次数，耗尽即失败；
- **20 个可通关关卡**（4~26 支箭，5×5 → 8×8），难度逐步加深；
- **关卡选择二级菜单**：按关解锁（通关第 N 关解锁第 N+1 关），已通关关卡可任意重玩，界面直接显示每关星级与整体进度；
- **通关进度保留**：进度只存在内存中，程序运行期间随时返回选关界面都能接着玩；退出程序即重置，无需手动存档；
- **按关记录最佳星数**：重玩同一关按历史最佳计分，总星数为各关最佳之和（满分 60 星），不会重复加分或退星；
- **随机模式**：主菜单可选无尽模式，每关箭头随机分布、难度逐关递增，生成器在构造上保证可通关；
- **AI 自动求解**（`S`）：用依赖图拓扑排序算出合法消除顺序，自动逐步演示通关；中途局面也能求解；
- **附加功能**：撤销上一步（`Z`）、提示（`H`）、星级评价（失误 / 撤销 / 提示各扣 1 星，满分 3 星，下限 0 星）、一键截图（`F2`）；
- **运行时合成音效**：射出、阻挡、按钮点击、撤销、提示、通关、失败、通关庆祝共 8 个音效，全部由 NumPy 生成波形，底部「音效」按钮或 `M` 键一键静音；
- **零素材依赖**（无图片、无音频文件、无字体文件），跨机器可直接运行。
